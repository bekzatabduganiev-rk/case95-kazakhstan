# CASE 95 — Судебная игра

Браузерная командная игра на русском языке. Исторические материалы дела Симпсона используются в условном гражданском споре по ГК Республики Казахстан, а не в реконструкции казахстанского уголовного суда.

## Запуск

Откройте `index.html` в браузере. Сервер и сборка не требуются. Основной цикл работает без интернета; видео, внешние источники и шрифты требуют сети (для шрифтов есть локальный fallback).

Две команды и ведущий играют с одного компьютера: вступительные речи → улики → допрос → правовые ситуации → учебное голосование. Прогресс хранится в localStorage этого браузера. После восстановления таймер приостановлен. Синхронизации устройств нет.

## GitHub Pages

В этом репозитории готовая игра находится в корне. Settings → Pages → Deploy from a branch → main → /(root). Локальный архив дополнительно включает вариант с папкой dist и GitHub Actions.

## Материалы

- ГК РК: https://adilet.zan.kz/rus/docs/K990000409_ (ст. 917, 940, 951, 952).
- Судебное решение: https://law.justia.com/cases/california/court-of-appeal/4th/86/573.html
- Исторический обзор: https://www.famous-trials.com/simpson/1862-home
- Видео пользователя: https://www.youtube.com/watch?v=uvTRY7JqynY

Схемы улик — собственные учебные визуализации, не фотографии подлинных материалов. Ответы свидетелей — обозначенные резюме или учебные задачи; вымышленные признания не используются. Процессуальные решения ведущего — игровые правила, не нормы ГК о допустимости. Американский уголовный стандарт не переносится в гражданскую модель Казахстана. Правовые тексты пересказаны кратко: перед занятием проверьте действующую редакцию.

Счёт: анализ 25, логика 25, допрос 20, право 20, стратегия 10. Победитель по баллам независим от голосования. Речи и свободные вопросы оценивает ведущий по видимым критериям. При истечении общего времени матч переходит к совещанию. При истечении времени хода незавершённое действие теряется.
