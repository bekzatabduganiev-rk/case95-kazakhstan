# CASE 95 — Суд над Симпсоном

Новая мультяшная версия [case95-kazakhstan](https://github.com/bekzatabduganiev-rk/case95-kazakhstan).

Главный экран: название и две кнопки. Начать игру открывает зал суда. Стол обвинения открывает 12 материалов; стол защиты — те же материалы и четыре задания для проверки аргументов. В карточке есть изображение, короткий факт и вопрос. Исторические детали и источники скрыты в раскрывающемся блоке.

Внизу зала ведущий добавляет +1 каждой команде, снимает балл или отменяет последнее изменение. Отметки обсуждения и счёт сохраняются в localStorage браузера. Минутный таймер запускается и останавливается нажатием. В панели ведущего можно заменить ссылку на видео и начать новое заседание. Видео по умолчанию сохранено из предыдущей версии; его доступность и содержание не удалось подтвердить.

## Запуск

Откройте index.html в современном браузере, сохранив папку assets рядом с ним. Сборка и установка зависимостей не нужны. Для удобного переноса есть отдельный файл «Суд-над-Симпсоном.html» со встроенными изображениями. Он открывается самостоятельно. Интернет нужен для видео, исторических ссылок и веб-шрифта; базовая игра и все иллюстрации доступны без него. Сохранение данных при file:// зависит от браузера; размещение на GitHub Pages даёт стабильный адрес для хранения.

## Обновление GitHub Pages

Замените в корне репозитория index.html, app.js, data.js, style.css и README.md. Добавьте папку assets целиком и RESEARCH.md. Сохраните существующие настройки GitHub Pages. Здесь нет изменения конфигурации публикации. После коммита в публикуемую ветку дождитесь завершения развёртывания GitHub Pages.

## Материалы

RESEARCH.md содержит пояснения по всем 12 карточкам и ссылки на источники. Это учебная подборка, а не полный архив дела и не официальный перечень из 12 улик. Предыдущие обязательные этапы с тестами по ГК РК заменены свободными дебатами по делу США. Судебные решения 1995 и 1997 годов разделены.

13 иллюстраций созданы встроенным ImageGen. Финальные промпты находятся в assets/prompts.json. Персонажи условные; иллюстрации не являются фото или точными копиями судебных экспонатов. Схема переезда полиции 13 июня не является географической картой и не показывает маршрут подозреваемого. Погоня 17 июня — отдельное событие.

## Проверка

Проверены синтаксис JS, 12 карточек и загрузка всех изображений в браузере, передача слова защите, начисление и отмена баллов, сохранение после перезагрузки, начало нового заседания, отображение при ширине 390 и 1440 пикселей. При этих проверках ошибок JS в консоли не обнаружено. Реальное видео и публикация на GitHub ещё не подтверждены.
